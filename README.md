# wvDoorClient

A client-only Fabric mod for Minecraft 1.21.11. It includes crystal effect suppression and local render hiding after attacking a crystal, customizable entity hitboxes, smooth floating damage indicators, a themed block highlight, and an in-game media HUD with desktop media-session controls.

## Build

- JDK 21 is required for Minecraft 1.21.11.
- Run `gradle build` from the project root to build both mods.
- Install **both** `build/libs/wvDoorClient-1.0.0.jar` and `wvlib/build/libs/WVlib-1.0.0.jar` in a Fabric 1.21.11 client with Fabric API and Mod Menu. `wvDoorClient` declares WVlib as a required dependency and will not load without it.
- The Windows DoorC Launcher is in [`doorc-launcher/`](./doorc-launcher/README.md). It installs standard versions and a separate DoorC 1.21.11 instance, checks GitHub Releases for launcher updates, and upgrades its existing installation; Microsoft sign-in and game launch still require an approved Microsoft application registration.

## Features and controls

- **WVlib:** required shared Fabric library mod with the public theme-color API used by the client's UI. Install its separate JAR alongside wvDoorClient.
- **Bundled resource packs:** LowOnFire, Side Shield, and Small Totem are installed and enabled automatically at client startup. The legacy Klas Romance pack is excluded because its outdated shader overrides break resource reloads on Minecraft 1.21.11.
- **Themed glass interface:** custom screens, HUD panels, inventory accents, and vanilla buttons use the configured colors with 20%-transparent surfaces, blurred backdrops, supersampled rounded edges, smooth button labels, animated hover states, smoothly moving category indicators and toggles, and a subtle slide when switching settings tabs. HUD widgets ease in with a small upward motion when they appear. A fading accent-colored trail follows the pointer across all Minecraft screens, not only the mod settings. The screenshot slideshow remains visible through menus.
- **Menu background slideshow:** four supplied in-game screenshots rotate with a smooth crossfade on the title screen, title-screen Options/settings screens, and the client's own settings menu. Images are center-cropped to match the screen without stretching; a subtle dark overlay keeps controls readable. In-world pause screens retain Minecraft's transparent world background.
- **Custom loading screen:** Minecraft's standard loading overlay is replaced with a softly glowing, theme-accented screen, a gently pulsing crystal mark, antialiased branding, and a smoothly animated rounded progress bar. It retains the normal resource-reload progress, completion callbacks, and fade transitions.
- **Localization:** the mod interface follows the selected Minecraft language and includes English, Ukrainian (`uk_ua`), and Belarusian (`be_by`) translations. The Russian locale (`ru_ru`) intentionally uses Belarusian text.
- **Settings menu:** press **Right Shift** in-game to open the custom settings screen. Its control-center layout groups settings into a category sidebar and a spacious content area with rounded setting cards and compact switch/slider/color controls. The larger settings viewport shows more options at once, with a draggable scrollbar for long categories. Use the tabs to configure crystal optimization, hitboxes, combat visuals, PvP HUD, media display, and the UI theme. The Theme tab includes **dark** (`#0B0F19` / `#0B0F19`), **light** (`#FDFBF7` / `#1A3A2B`), and **orange** (`#1A1616` / `#FF5722`) presets (background / accent), plus editable primary and muted text colors. All glass panels keep a fixed 20% transparency. Click a color to open its RGB sliders or enter a six-digit `#RRGGBB` HEX value; valid HEX values preview immediately and are saved when the picker is closed. Select **Edit HUD layout** to drag each widget to move it or drag its lower-right corner to resize it from 50% to 200%; positions and individual widget scales are saved to the client config.
- **Inventory and hotbar theme:** the player inventory receives the configured dark panel tint and accent-colored edges. The hotbar has a translucent rounded panel, individually softened slots, and a rounded selected-slot highlight. Its background and accent follow the Theme settings, with the same fixed panel transparency, while vanilla item rendering, offhand, indicators, and slot interactions remain intact.
- **Screenshots:** use **Right Shift → Screenshots** to browse captures from the Minecraft `screenshots` folder, preview the full image scaled to fit, copy the selected PNG to the system image clipboard using the OS clipboard API, refresh the list, or open the folder in the operating system file manager.
- **Friends:** use **Right Shift → Friends** to keep a local list of Minecraft usernames and see which listed players are currently on your server. This list is stored on this device only; it does not send friend requests or provide cross-server chat.
- **Skin Studio:** the title screen and pause menu render your Minecraft account skin as a real 3D player model, even if you have never added a skin to the mod library. The account skin is loaded through Minecraft's own skin manager. **Skin Menu** opens a wardrobe-style local library with a larger preview. **Add Skin** opens the operating system's native file picker (Windows File Explorer dialog) for selecting a 64x64 PNG. You can also enter a Minecraft username and load that profile's public skin; it is saved and applied locally without uploading it to your account. Select a local PNG to preview, choose Classic or Slim, and use **Apply Skin** to wear it. Applying a local PNG starts a continuous 10-minute timer; after that the mod checks the signed-in account's Minecraft ownership and, if licensed, uploads the selected PNG to the official Minecraft profile. Other clients may need time to refresh their skin cache. Without a license, it stays local. The access token is used only for HTTPS requests to Mojang's Minecraft services and is never saved or logged. Stopping the local skin does not revert a skin already uploaded to the official profile.
- **Custom hitboxes:** enabled by default; press **B** to toggle. When enabled, the mod suppresses vanilla F3+B entity hitboxes and renders the configurable custom outlines instead; other vanilla debug renderers are unaffected. Configure colors as 8-digit ARGB hex strings (or 6-digit RGB strings) in the Hitboxes tab; range, line thickness, and other options are available there too.
- **Crystal and anchor optimizer:** remove explosion/smoke particles and hide attacked crystals locally for up to 12 client ticks while awaiting server confirmation. For crystal placement on obsidian/bedrock and respawn-anchor interactions, the mod clears only Minecraft's local four-tick right-click repeat delay after the normal use action. It does not pre-send, replay, reorder, or bypass server packets, server cooldowns, latency, or anti-cheat checks; anchor combos still require the player to perform each valid interaction.
- **Combat visuals:** configure the split crosshair, target HUD (name, health, and distance), and a distinct hitbox outline for the entity under the crosshair in the Combat tab. While holding a bow or crossbow, the arrow total in your inventory appears in a compact chip beside the crosshair, independently of the custom-crosshair toggle.
- **Damage particles and block highlight:** smooth floating damage numbers appear when living entities lose health. The selected block receives a translucent, configurable-color fill and softened outline; disable the custom highlight to use the optional vanilla outline instead. Both effects and their colors are available in **Visuals**.
- **PvP HUD:** configurable Keystrokes, real left/right CPS over a rolling one-second window, a compact item-counter strip for Totems, Golden Apples, Enchanted Golden Apples, Ender Pearls, End Crystals, and Obsidian, coordinates and cardinal direction, an armor panel with equipped-item icons, empty-slot indicators and durability bars, and up to five active potion effects with timers. The item counter shows live inventory totals and can be moved and resized in **Edit HUD layout**. Keystrokes use a compact floating W/A/S/D, Space, and mouse-button layout with flat translucent caps, subtle outlines, and bold antialiased sans-serif labels instead of a large backing panel; the matching CPS display is similarly minimal. These widgets remain independently movable and resizable.
- **Media HUD:** starts as a compact pill showing the track, artist, and playback progress, then smoothly expands on hover to reveal high-resolution rounded album art and working previous/play-pause/next buttons. The controls can be clicked while another Minecraft screen (such as inventory) is open or used through the configurable media keybindings. The widget remains movable and resizable in **Edit HUD layout**.
- **HUD sizing:** the coordinates panel is wider so long X/Y/Z values fit inside; its draggable preview matches the in-game HUD.
- **Extra utilities:** client-only AntiDarkness suppresses the Darkness effect's world-darkening calculation; Fullbright, time/weather overrides, reduced/minimal particles, temporal motion blur and chunk-load fade, block-outline toggle, camera-only Freelook, smooth hold-to-zoom (C by default), configurable toggle sprint/sneak, Reach display, and an attack-combo counter. Set up features under **Visuals** and **Movement**; rebind Smooth Zoom, Freelook (V by default), Toggle Sprint, and Toggle Sneak in Minecraft Controls. Visuals do not change server state or extend attack reach.
- **Motion Blur:** blends the current frame with a persistent copy of the previous frame. Toggle it in **Visuals** to remove the effect; the strength control adjusts frame persistence. This is temporal frame blending (not the old screen-edge fade); rapid changes can show a short visual trail. Chunk Animator remains a separate brief accent fade when chunks load.
- **Media:** bind Play/Pause, Next, and Previous in Controls. Media commands are sent only while Minecraft has focus. Linux requires `playerctl` with an active MPRIS player; Windows queries the current Windows media session; macOS controls Spotify through AppleScript.
- **Discord Rich Presence:** when the Discord desktop app is running, the mod connects to its local IPC and publishes `wvDoorClient` as the application activity. The activity shows whether you are in the main menu, singleplayer, or multiplayer, without including the server address. Toggle it in the Media tab; no bot token or external service is used.
- **Media artwork, playback time, and effect icons:** the media HUD shows elapsed and total track time with its progress bar. If a Windows media session stops updating its playback position, the client keeps elapsed time moving between polls; unknown/live duration is shown as `--:--`. Windows media sessions provide album art when the active app exposes a thumbnail; the HUD loads it as a bounded, temporary client texture. Active effects use their vanilla mob-effect icons, with a color fallback for custom effects without an icon.

Media polling runs on a daemon worker and never blocks rendering. Browser playback is available when the browser publishes an OS media session. macOS support is limited to Spotify; app/browser metadata APIs vary by platform.

## Project layout

```text
src/main/java/dev/crystalutility/
  CrystalUtilityClient.java
  CrystalVisibility.java
  config/       JSON config and custom settings screen / Mod Menu integration
  media/        platform media-session polling and commands
  mixin/        client crystal renderer and particle hooks
  render/       hitbox, combat, media, and PvP HUD renderers
src/main/resources/
  fabric.mod.json
  crystalutility.mixins.json
  assets/crystalutility/media-windows.ps1
```
